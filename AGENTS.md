# Website maintenance

Preserve Anna's approved copy and editorial design unless she requests a change. Use regular Advercase, never bold, and Crimson Text body copy. Brand colour is #3e0000. Photography is monochrome.

This directory is the repository root. The canonical repository is https://github.com/brandingwithanna/website.git. Use only main. Push all completed website changes to origin/main after the build passes; this is Anna’s standing instruction. Never force-push or overwrite remote work. Before every push run npm run build and resolve failures. Check layout at 390px and 1440px after visual changes. Write a clear commit message and push to the configured GitHub origin/main when the user's requested change is complete. Never claim deployment until Vercel confirms it. Do not publish course PDFs, private documents, credentials or personal account data.
